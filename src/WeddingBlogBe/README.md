# WeddingBlogBe

ASP.NET Core Web API per la gestione backend del wedding blog.

## Comandi

```bash
dotnet restore
dotnet run
```

## Endpoint iniziali

- `GET /` restituisce il nome dell'API.
- `GET /health` restituisce lo stato del servizio.

La policy CORS di sviluppo accetta richieste dalla Vite app su `http://localhost:5173`.
